# The Gripiz Landing Page

One-page premium BBQ restaurant landing page built with Next.js + Tailwind CSS.

## Tech
- Next.js (App Router)
- Tailwind CSS
- Responsive reusable component structure

## Folder Structure

```txt
app/
  globals.css
  layout.tsx
  page.tsx
components/
  FadeInSection.tsx
  Footer.tsx
  FromFire.tsx
  Gallery.tsx
  Hero.tsx
  Location.tsx
  MenuList.tsx
  Navbar.tsx
  SignatureMenu.tsx
  Experience.tsx
  types.ts
data/
  menu.json
public/
  images/ (visual placeholders)
  videos/
    hero-placeholder.mp4
    README.md
```

## Run

```bash
npm install
npm run dev
```
